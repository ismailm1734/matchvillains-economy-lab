# Heist Economy Lab

An interactive, single-page simulator that models how a casual match-3 game's difficulty curve and monetization levers affect player retention and revenue.

## What it does

Adjust design levers (difficulty, drop-off points, monetization pressure, etc.) and see how they ripple through a simulated player cohort in real time — difficulty curve, drop-off chart, and the core retention/monetization trade-off, all rendered live in the browser.

## Usage

Just open `matchvillains-economy-lab.html` in any modern browser. No build step, no dependencies — it's a self-contained HTML file with inline CSS/JS.

```bash
open matchvillains-economy-lab.html
```
